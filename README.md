# Axios Macro Bot

Axios Macro 뉴스레터를 Gmail에서 가져와 한국어 시장 브리핑으로 요약하고, HTML 이메일로 전달하는 Python 자동화입니다.

## 실행 흐름

1. Gmail에서 `Axios Macro` 발신 메일 중 미처리 메일을 찾습니다.
2. 본문과 `View in browser` 원문 링크를 추출합니다.
3. OpenAI로 주요 항목 2~4개를 선정해 거시경제 초보자용 한국어 해설을 생성합니다.
4. 결과를 이메일로 보내고 Gmail 라벨로 처리 상태를 기록합니다.

## 브리핑 구성

기존 고정 섹션 대신 각 주요 항목을 다음 순서로 설명합니다.

- **핵심 내용**: 원문의 주요 사실과 수치, 발언 주체를 정리합니다.
- **쉽게 풀면**: 일상적인 말로 풀어 설명하고 필요한 배경을 덧붙입니다.
- **왜 중요한가**: 원문에 근거해 경제와 생활에 갖는 의미를 설명합니다.

금리·인플레이션·환율·채권 등 어려운 용어는 처음 등장할 때 짧게 설명합니다.
원문의 사실·수치·단위·비교 기준·인과관계와 불확실성을 보존하도록 지시하며,
편집자의 해석은 `해석:`, 일반 개념은 `배경 설명:`, 비유는 `이해를 위한 비유:`로 구분합니다.
원문 본문은 문장부호를 바꾸지 않고 편집 지시와 분리해 모델에 전달합니다.

전체 읽기 시간은 약 5~10분을 목표로 합니다(작성 참고: 공백 포함 약 3,000~5,000자).
원문이 짧거나 근거가 부족하면 항목 수와 분량보다 정확성을 우선합니다.
영어 표현, 문장 뜯어보기, 일반적인 투자 조언 섹션은 포함하지 않습니다.
이 구성과 분량은 모델에 전달하는 작성 지침이며, 실제 결과의 정확성과 읽기 시간을
코드로 보장하지는 않습니다.

기존 HTML 디자인, Gmail 수신·발송 및 중복 방지 로직은 그대로 사용합니다.
GitHub Actions의 기존 예약 실행은 매일 UTC 23:30(한국 시간 다음 날 오전 8:30)이며,
수동 실행 시 `retry_failed`로 실패 메일을 재시도할 수 있습니다.

## 설정

`.env.example`을 참고해 아래 환경 변수를 설정합니다. GitHub Actions에서는 같은 이름으로 repository secrets를 등록합니다.

- `OPENAI_API_KEY`
- `EMAIL_USER`
- `EMAIL_PASS` — Gmail 앱 비밀번호
- `RECEIVER_EMAIL`

로컬에서는 Python 3.11에서 다음을 실행합니다.

```bash
python -m pip install -r requirements.txt
python main.py
```

## Gmail 라벨

- `AXIOS_PROCESSING`: 발송을 시작한 메일입니다. 발송 후 상태 기록이 불완전할 때 중복 발송을 막기 위해 유지됩니다.
- `AXIOS_PROCESSED`: 정상 발송을 마친 메일입니다.
- `AXIOS_FAILED`: 발송 또는 분석에 실패한 메일입니다. 자동 재시도하지 않습니다. GitHub Actions의 수동 실행에서 `retry_failed`를 선택하면 실패분을 다시 처리하며, 성공한 메일의 라벨은 자동으로 제거됩니다.

## 테스트

```bash
python -m unittest discover -s tests
python -m compileall -q analyzer.py config.py email_reader.py main.py tests
```

테스트는 OpenAI와 메일 처리를 모의 객체로 대체하므로 API 호출이나 실제 이메일 발송이 없습니다.
분석 지침, 원문 보존, HTML 출력 호환성 및 발송 성공·실패 시 상태 처리를 확인합니다.

## Global News Brief (2026-10-13 전환)

기존 Semafor 예약 작업이 이제 `global_news.py`를 실행합니다. Axios 파일·모델·예약은 그대로입니다.
기존 `semafor.py`는 회귀 테스트용 레거시 구현이며 별도 예약 발송하지 않습니다.

- 구성: Semafor Flagship + Washington DC + 뉴닉 데일리 뉴스 + Nature Briefing Daily
- 부계정에서 원문을 수집하고 기존 본계정으로 `🌐 통합 뉴스 요약 · YYYY-MM-DD` 한 통을 발송합니다.
- 시간: 한국 시간 월~금 23:30 (UTC 14:30), GitHub 예약 실행은 지연될 수 있습니다.
- 수집: 직전 평일 23:30 이상 ~ 해당 회차 23:30 미만의 Gmail 수신분.
  월요일에는 금요일 밤 이후와 주말 수신분도 포함합니다. 늦게 도착한 원문은 다음 회차에 포함됩니다.
- 읽음/보관 여부와 무관하게 All Mail을 검색하고 스팸·휴지통은 제외합니다.
- 소스가 일부 없으면 수신된 것만 요약하고 빠진 소스를 표시합니다. 모두 없으면 예약 실행을 실패로 표시합니다.
- 순수 인증·환영 메일은 제외합니다. 같은 원문의 복제본과 같은 사건의 중복 보도를 병합합니다.
- 발신 필터: Semafor 두 기존 주소, `briefing@nature.com`, 정확한 `newneek.co` 발신 도메인.
  뉴닉 첫 실제 뉴스레터 수신 후 From 주소/본문 파싱을 확인해야 합니다.

### 구독 상태

2026-10-13 Nature Briefing Daily의 구독 신청과 이메일 확인을 완료했습니다.
뉴닉은 2026-10-13 사용자가 가입을 완료했으며 부계정에서 구독 환영 메일 수신을 확인했습니다.
확인된 발신 주소는 `whatsup@newneek.co`이며 수집 필터에 포함됩니다. 사용법·환영 메일은 제외합니다.
두 신규 매체의 실제 정규 뉴스레터 MIME을 이용한 운영 검증은 첫 수신 후 가능합니다.

### 편집 기준

미국 정치, 한국 정치·사회, 글로벌 지정학, 과학, 기술을 중심으로 주제별 최대 5개 섹션을 작성합니다.
경제/투자 관련성이 없어도 중요한 사건을 포함하고 AI가 과학 전반을 대체하지 않게 합니다.
기존 compact bullet 형식(본문 1,800자, bullet 120자, 섹션당 최대 3 bullet)을 유지합니다.
오늘의 3줄·도입부·결론은 없습니다. 사실·주장·해석과 연구의 한계, 수치·단위·불확실성을 보존합니다.
초안과 원문 대조 검토의 2단계 생성, JSON 검증·수정 절차를 유지합니다.
각 bullet에 원문 식별자를 표시하고 말미에 원문 링크를 붙입니다.
웹 버전 링크가 없는 경우 해당 원문의 Message-ID를 이용한 Gmail 검색 링크를 붙입니다.
내용의 충실성과 편집 균형은 모델 지침이며 기계적으로 보장되지 않습니다.

### 실행·중복 방지

기존 Semafor secrets와 수신/발신 설정을 재사용합니다.
기존 `SEMAFOR_DAILY_YYYY-MM-DD` 예약 라벨과 concurrency 그룹을 유지하여 전환 중 중복을 방지합니다.
SMTP 인증 후 날짜를 먼저 예약하고 발송합니다. 발송이 불확실해도 예약을 삭제하지 않습니다.
이는 최대 한 번의 발송 시도이며, 실제 미발송 확인 후에만 예약을 수동 해제해 재실행합니다.
회차가 완전히 누락되면 해당 날짜를 지정해 수동 복구합니다.

```bash
python global_news.py --scheduled
python global_news.py --date 2026-10-13 --dry-run --output preview.eml
python -m unittest discover -s tests
```

Actions 수동 실행의 `dry_run=true`는 실제 원문/API를 이용하지만 이메일 발송과 예약은 하지 않습니다.
코드 push 시에는 테스트만 실행하고 메일을 발송하지 않습니다.
새 테스트는 매체 분류, Axios 제외, 인증 메일 제외, 23:30 경계·주말 수집, 원문 링크,
통합 제목·누락 소스·기존 중복 방지 라벨을 확인합니다.
